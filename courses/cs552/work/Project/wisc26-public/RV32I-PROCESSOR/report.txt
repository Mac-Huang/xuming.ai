The prefetcher was added so the instruction cache can look ahead while the processor is running normal code. When the processor misses on an instruction cache line and that line finishes loading, the cache also tries to bring in the next line of instructions. This helps because most programs run through nearby instructions in order. The prefetch work is only done when there is no real processor request waiting, so it should not delay an instruction or data access that the processor actually needs right away.

The cache associativity was increased so different memory blocks have more places where they can live in the cache. Instead of one address mapping to only one possible slot, each set has four possible ways. On a lookup, the cache checks all four ways and uses the one that matches. When a new line must be loaded, the cache first chooses an empty way if one exists, and otherwise rotates through the ways. This reduces conflict misses, where useful cache lines used to evict each other just because their addresses landed in the same slot.

The branch predictor was improved to make better guesses about where the program will go next. It uses a branch target buffer to remember recently seen branches, their targets, and whether they usually go taken or not taken. If the branch has not been seen before, the predictor still makes a simple guess: jumps are taken, backward branches are usually taken, and forward branches are usually not taken. A small return address stack also helps returns go back to the right call site. When the guess is wrong, the processor still corrects the program counter, but a better guess means fewer wasted cycles.

Before these optimizations, the local hart test suite showed an average CPI of about 3.36 across the 25 processor tests. After adding the prefetcher, the 4-way cache behavior, and the improved branch predictor design, the average CPI was about 2.98 on the same tests. Lower CPI means the processor is retiring instructions with fewer cycles on average, so the final design is faster than the earlier version.
