## Contents

Source files, test inputs and expected outputs, assignment materials, lecture notes, paper analyses, research reports, diagrams, and required supporting libraries. Working variants are preserved rather than silently overwritten.

`coursework-manifest.json` records the source-relative path, published path, size, and SHA-256 of each imported file. The original Courses.zip and all extracted files remain in the local Courses folder.

## Omitted from the public copy

Nested Git history, editor caches, generated build output, duplicate ZIPs, incomplete generated documentation, reference textbooks, course-access passwords, and personal assessment exports. This is a source archive, not a claim that every historical project compiles or passes its tests.

Course materials, papers, starter code, and dependencies retain their original authorship and licensing. No blanket license is applied to third-party coursework materials.
