# Efficient Virtual Memory for Big Memory Servers

The paper challenges the long-standing assumption that page-based virtual memory is universally efficient. It argues that for modern “big-memory” workloads—such as databases, in-memory caches, and graph analytics—paging introduces significant overhead without delivering proportional benefits. These workloads operate on large, contiguous memory regions, exhibit stable allocation patterns, and rarely rely on features like swapping or fine-grained page protection.

The core idea is to **bypass page-based translation for most memory accesses** by introducing a *direct segment*. A direct segment maps a contiguous virtual address range directly to contiguous physical memory using a simple base–limit–offset mechanism. This eliminates TLB lookups and thus removes TLB miss penalties for that region. Conventional paging is retained for the rest of the address space, preserving compatibility and flexibility.

This paper inspired me that LLM training/inference shares the same workload with the one discussed. First, they all have large, persistent memory regions: model weights and KV cache, which are allocated once, long-lived and dominating memory footprint. Second, weak locality: especially in the LLM decode stage, the attention layer reads KV cache across sequences, which has poor temporal locality because it grows at each step. Third, they both pay for VM flexibility we don’t use: weights are read-only, KV cache is append-only / RW, and neither copy-on-write nor demand paging. Therefore, I believe we can implement the same idea, direct segment, to map the model weights and KV cache to the memory: create two primary-region classes: **Weight region (**read-only, allocated once at model load, ideally contiguous) and **KV region** (large reserved address space, backed incrementally, contiguous). I probably need to read more papers to verify this idea.

In a nutshell, this paper argues that page-based virtual memory is increasingly misaligned with modern big-memory workloads. By introducing direct segments, it offers a simple yet powerful alternative that eliminates most address translation overhead while preserving compatibility. It is also intriguing to be extended to other works close to AI nowadays, especially LLM inference/training getting popular these days. The work highlights the importance of rethinking system abstractions in the context of evolving workload characteristics.
